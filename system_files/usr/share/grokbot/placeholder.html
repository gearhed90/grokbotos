Grok Bot OS is on

This screen is a placeholder. Sign-in and subscriptions are handled by the Grok Bot app (or its web app). This OS creates no accounts and stores no passwords.

The default image includes the Grok Bot RPM. This page only appears when the image was built without it, using GROKBOT_DISABLE_BUNDLED_APP=1. See docs/GROKBOT_APP.md for how.

  • Config file: /etc/grokbot/app.conf
  • Switch apps: Super+Space or Alt+Space
  • Back to Grok Bot: Super+G or Alt+G
  • Cycle windows: Alt+Tab · Close a window: Alt+F4
  • Session log: ~/.local/share/grokbot/shell.log
  • Recovery console: Ctrl+Alt+F2 (the admin account made at install)
